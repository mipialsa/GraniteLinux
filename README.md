# GraniteLinux
Granite linux is based of debian and bedrock linux. The dektop enviorment is XFCE for low pc.


Is a Spanish project to create a fast, and secure linux based of Debian.


# Summary

Granite Linux is a lightweight, minimalist GNU/Linux distribution based on Debian Stable, designed to deliver a fast, stable, and clean desktop experience. It combines the reliability of Debian with optional Bedrock Linux compatibility, allowing advanced users to integrate packages from multiple Linux distributions.

Built around the XFCE desktop environment, Granite Linux focuses on low resource usage, simplicity, and ease of maintenance. Only essential software is included, providing a responsive system suitable for both older and modern hardware.

## Features

* Based on Debian Stable.
* Optional Bedrock Linux compatibility.
* XFCE desktop environment.
* Lightweight and fast.
* Minimal software installation.
* Minimalist granite-inspired design.
* GRUB bootloader.
* Easy to customize.

Granite Linux is designed for users who value stability, performance, and a clean desktop without unnecessary software.
